# Pomopet macOS

Pomopet is a macOS desktop Pomodoro concept: a cute desktop pet, humorous break reminders, and configurable off-work nudges.

## Artifacts

- Product design: `docs/superpowers/specs/2026-08-21-pomopet-macos-design.md`
- HTML prototype: `prototype/index.html`

## Prototype

Open `prototype/index.html` in a browser. It is a static clickable prototype with no build step.

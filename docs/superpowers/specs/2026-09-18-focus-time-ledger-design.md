# Pomopet 专注时间账本设计

## 目标

在不改变首页 Todo 高使用频率路径的前提下，让 Pomopet 记录实时专注与用户手动补记的专注，并在现有“时间回顾”里按实际时间展示全天分布。

本期不做周复盘、AI 时间分析、导出、云同步，也不把 Pomopet 变成项目管理工具。

## 用户路径

### 1. 首页 Todo

Todo 继续位于计时卡片中的“今日待办”，保留标题、优先级、预计番茄、完成、编辑和删除。

每个 Todo 有一个本次专注时长，单位为分钟，默认从全局番茄预设得到。用户可以在编辑 Todo 时改为 1 到 180 分钟。

- 空闲 Todo 显示开始图标。
- 当前运行 Todo 的图标显示暂停。
- 当前暂停 Todo 的图标显示继续。
- 开始、暂停和继续的点击目标至少为 32x32 像素，整块按钮均可点击，不能依赖鼠标指针样式。

Todo 的计划开始时间是可选的一次性字段。未配置计划时，它就是普通 Todo；计划本身不是实际工作记录。

### 2. 计划开始与冲突

计划到点时：

- 没有正在运行或暂停的计时器：自动启动该 Todo 的设定时长。
- 正在运行或暂停同一个 Todo：不重复启动。
- 正在处理另一个 Todo：不自动切换，显示冲突提示。

冲突提示只有两个决定：

1. 继续当前任务：保持当前计时，计划 Todo 标为待开始；当前轮结束后再次提示。
2. 切换并开始计划任务：先停止当前专注并结算已经发生的实际时间，再启动计划 Todo。

应用未启动或用户未处理提示而错过开始时间时，不补造计时记录。

### 3. 手动补记

“补记时间”作为低频 Tab，固定放在“提醒计划”之后。

第一期仅支持补记专注，字段为：

- 关联 Todo（可选）
- 开始时间
- 结束时间

不显示备注字段。结束必须晚于开始，且不能晚于当前时间。

补记与既有专注记录重叠时，用户只能选择“只保留未重叠部分”或返回修改；不能静默重复计算。与会议重叠允许保存。

补记落入与实时专注相同的 Activity Ledger，带来源字段 `manual`，因此同样累计 Todo 实际耗时并写入时间回顾。

### 4. 时间回顾

继续使用现有“时间回顾”Tab：

- 日期下拉框切换到所选日期的摘要、时间线和会议甘特图。
- 工作日时间线为可纵向滚动的轴，任务块的高度与真实时间比例一致。
- 专注优先覆盖会议，避免主统计双计；会议甘特图完整展示会议块。
- 每个时间块能通过鼠标 hover 或键盘 focus 显示任务名、来源、起止时间、时长和交叠说明。

## 数据与迁移

继续使用 Electron `userData/pomopet-state.json` 与现有临时文件 + rename 原子写入。

Todo 新字段：

```json
{
  "focusMinutes": 25,
  "scheduledStartAt": null,
  "scheduledStatus": "none"
}
```

`scheduledStatus` 只用于一次性计划的运行状态：`none`、`pending`、`conflict`、`missed`、`started`。旧 Todo 迁移后使用 `focusMinutes: null`，开始时回退到当前全局番茄时长。

Activity interval 新字段：

```json
{
  "source": "timer | manual"
}
```

旧 interval 默认 `source: "timer"`。

## 边界与不变量

- 真实时间只来自计时器已结算片段或显式补记。
- 计划从不直接增加 `spentMs`、完成番茄或时间线时长。
- 同一段专注只可入账一次。
- 删除 Todo 不删除历史 interval 的标题快照。
- 时间线统计优先级保持 `excluded > focus > meeting > break > unrecorded`。
- 所有运行时命令继续通过 `AppRuntime.command()` 串行写入并原子持久化。

## 验收

1. Todo 仍在首页，保留优先级、编辑和删除，并可设置专注时长。
2. Todo 行的开始图标在运行后变暂停，暂停后变继续。
3. 计划开始能在空闲时自动启动，冲突时必须等用户决策。
4. 手动补记持久化、累计到 Todo，并在重启后仍出现在时间回顾。
5. 补记专注与会议重叠时，专注优先出现在主时间线，会议甘特图不缺失。
6. 日期选择真切换到另一份数据。
7. 纵轴时间线可滚动，时间块 hover/focus 能给出完整明细。

产品目标：这不是“番茄钟旁边放一只宠物”，而是一只陪伴用户工作的桌面宠物。番茄钟和闹钟负责在正确时间触发宠物行为；可爱形象、幽默中文文案、动作和简单语音负责提供情绪价值。

首个安装目标是 Apple Silicon（arm64）Mac。未来只有在宠物足够可爱、互动足够好玩且核心产品得到验证后，才考虑 Windows；当前不要实现 Windows 发行版，但计时、闹钟、宠物状态和文案逻辑应保持跨平台，平台窗口、通知、登录项和打包能力放在适配层。

必须完成的核心能力：

1. 正确可靠的番茄钟：25/5、50/10、自定义，任务名，开始、暂停、继续、停止、完成，睡眠/唤醒和重启后按目标时间恢复，完成事件只触发一次。
2. 定时闹钟：一次性和按星期重复，标签、启用/停用、编辑、删除、稍后提醒、关闭；应用运行时由宠物提醒，退出时尽可能使用系统通知兜底。
3. 桌面宠物：透明、置顶、可拖动、记住位置、不抢键盘焦点，可从菜单栏隐藏和恢复。
4. 一个真正可爱的核心宠物形象。不要再使用突兀的 CSS 几何块充当角色。优先使用自有生成的高质量位图/动画资产；如工具不可用，选择许可清楚的精致资产并记录来源。角色是产品第一卖点。
5. 宠物状态：专注时安静陪伴；完成任务时庆祝夸奖；休息时叼玩具邀请离开电脑；提醒未回应时先委屈、再气鼓鼓；下班时躺倒、装死或拖住窗口边缘；所有强提醒可关闭且不得强制关机、息屏或阻断整个系统。
6. 轻量亲密互动：摸头、直接投喂、扔球、请求安慰。每次 10 到 20 秒，没有亲密度数值、库存、升级树、商城、失败或惩罚。
7. 一套简单统一的可爱音色，同一声线用 happy、cute、comfort、sarcastic、angry、sleepy 等情绪演绎。优先预生成少量本地音频并随应用打包，不依赖运行时云 TTS。语音可关闭、可调音量、不得重叠；音频不可用时视觉提醒继续工作。
8. 内置中文幽默文案，不依赖 AI 或 API key；同类提醒避免连续重复。至少覆盖任务完成、休息、闹钟、下班和被忽略后的提醒。

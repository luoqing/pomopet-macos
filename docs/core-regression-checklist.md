# Pomopet 核心流程测试 / 回归清单

这份清单用于每次新增功能、修 bug、改 UI、改提醒逻辑或打包前验收。AI 不能只说“已测试”，必须按本文件回填实际命令、实际操作路径和未覆盖风险。

## 常见 bug 反馈归类

从现有提交、交付报告和规格文档看，Pomopet 最容易反复出问题的地方不是需求理解，而是实现细节：

- 桌面宠物 IPC 和倒计时容易被新功能改坏，历史上已有 `fix: restore desktop pet ipc and countdown`。
- 宠物动作资源容易映射错，历史上已有 `fix: use blue cup water pet animation`。
- Linux 自动测试和交叉打包不能代表 macOS 实机通过，透明窗口、通知权限、登录项、全屏空间、多显示器必须真机验收。
- 番茄钟暂停、继续、停止、提前完成、休息续接、重启恢复这类状态机路径容易只测 happy path。
- 提醒计划容易重复触发、漏触发、snooze 改坏基础计划、休眠恢复后补发多条或不补发。
- 编辑表单容易被倒计时刷新、AI 返回、提醒触发覆盖，导致用户正在输入的 Todo、提醒、人设或设置丢失。
- 宠物气泡、系统通知、TTS 容易文案不一致、重复播放、低优先级覆盖高优先级。
- 宠物窗口容易抢焦点、位置丢失、拖出屏幕、隐藏后无法找回，尤其在 Mission Control、全屏 App 和多显示器下。

## 每次改动前

- 写清本次改动影响哪些模块：番茄钟、Todo、提醒计划、下班提醒、宠物窗口、语音、AI 文案、持久化、打包。
- 先列出可能被改坏的旧行为，至少覆盖上面“常见 bug 反馈归类”里相关条目。
- 如果改的是计时、提醒、恢复、持久化、窗口、TTS、AI 文案，必须先补或更新自动测试，再改实现。
- 如果改的是纯文案或样式，也要跑 UI 冒烟，确认按钮可见、文字不重叠、宠物资源不丢。

## 自动化门禁

每次交付前至少运行：

~~~bash
npm run lint
npm run test
npm run build
~~~

如果改到 UI、控制台、宠物窗口展示、资源路径、按钮交互：

~~~bash
npm run test:ui
~~~

如果改到计时器、提醒调度、snooze、跨日、睡眠/重启恢复、事件去重：

~~~bash
npm run test:soak
~~~

回填格式：

~~~text
自动化结果：
- npm run lint: 通过/失败，关键输出：
- npm run test: 通过/失败，测试文件数和失败用例：

- npm run test:ui: 通过/失败/未跑，原因：
- npm run test:soak: 通过/失败/未跑，原因：
~~~

## 10 分钟核心手动回归

### 1. 启动与基础窗口

- 启动应用后控制窗口可见，无控制台错误。
- 桌面宠物出现，透明背景正常，不显示白边或破图。
- 宠物窗口不抢键盘焦点；在其他 App 输入文字时，宠物不打断输入。
- 菜单栏图标可打开控制台、隐藏宠物、恢复宠物、退出应用。
- 拖动宠物到屏幕边缘后重启，位置能恢复且不会跑出可见工作区。

### 2. Todo 与番茄钟主链路

- 新增 Todo：输入标题、优先级、预估番茄，保存后列表出现。
- 从新 Todo 开始专注，任务名与当前 Todo 一致，倒计时开始减少。
- 点击暂停后倒计时停止减少，宠物状态切到非专注动作。
- 点击继续后从暂停时剩余时间继续，不重置、不跳秒、不重复创建 session。
- 点击停止后回到空闲态，不累计完成番茄，不触发完成奖励。
- 再开始一次专注，点击提前完成后累计当前 Todo 的番茄和用时，并触发奖励气泡/动作/语音。

### 3. 休息与续接

- 番茄完成后进入休息，不自动开始下一颗。
- 休息倒计时可以暂停、继续、跳过。
- 休息结束后出现继续刚才的任务、换下一件、先不开始。
- 选择继续刚才的任务，会沿用休息前 Todo 和番茄时长开始下一颗。
- 原 Todo 被完成或删除后，休息结束不应继续指向失效 Todo。
- 不操作让气泡收起后，主窗口仍保留待选择状态，不偷偷开始计时。

### 4. 提醒计划

- 新建一次性提醒，设置为当前时间后 1 到 2 分钟，能到点触发。
- 新建每周提醒，保存后下次触发时间显示正确；禁用后不触发，重新启用后恢复。
- 新建间隔循环提醒，工作时段内按间隔计算下次提醒，时段外不触发。
- 点击“再睡 10 分钟”只生成 snooze occurrence，不改变原计划的基础节奏。
- 删除或禁用原计划后，关联的待触发 snooze 被清理。
- 同一分钟多个提醒到期时，不重复弹同一个 occurrence，不漏掉不同 occurrence。

### 5. 下班提醒

- 到下班时间后出现下班提醒，动作使用用户选择的趴下或装死。
- 点击稍后提醒后，当天延后触发；点击当日关闭后当天不再触发。
- 忽略下班提醒后只升级一次，不持续刷屏。
- 变大遮挡期间，普通唠嗑和低优先级互动不会覆盖下班提醒。

### 6. 宠物展示、通知和语音

- 宠物可见时，番茄完成、提醒计划、下班提醒优先走宠物气泡。
- 宠物隐藏时，关键事件走 macOS 系统通知兜底。
- 气泡、系统通知、TTS 使用同一句文案。
- 新高优先级事件到来时，旧低优先级语音停止，高优先级语音播放。
- 语音模式为关闭时不播放；仅关键提醒时普通唠嗑不播放。
- 播放失败或无音频设备时，视觉提醒仍出现，不阻塞主流程。

### 7. AI 文案与回退

- 未配置 API Key 时，提醒仍能使用内置文案正常触发。
- API Key 错误、断网或超时，提醒不延迟丢失，1.5 秒左右回退本地文案。
- AI 迟到结果不会替换已经展示的气泡、通知或 TTS 文案。
- “生成一句测试文案”只影响测试区域，不重置设置表单，不触发语音。

### 8. 编辑保护

- 编辑 Todo 时触发倒计时刷新，输入框内容不被覆盖。
- 编辑提醒计划时有新提醒到期，草稿内容不被覆盖。
- 编辑人设或声音设置时点击 AI 测试，未保存字段不丢。
- 有未保存修改时切换页签、切换提醒项、关闭控制窗口，会出现确认；选择继续编辑后草稿保留。
- 保存失败时表单保持打开，错误可见，输入内容不丢；取消后恢复上次保存值。

### 9. 重启与持久化

- 修改 Todo、提醒、人设、声音、下班规则、宠物位置后退出重开，数据保持。
- 专注中退出重开：倒计时按目标结束时间恢复，不从原始时长重来。
- 暂停中退出重开：仍是暂停态，剩余时间不继续减少。
- 休息选择待处理时退出重开：仍能继续、换下一件或先不开始。
- 到期但未展示的专注完成只补记一次，不重复加番茄。
- 损坏或缺字段的旧数据启动后不崩溃，能迁移到默认值。

## macOS 实机验收

这些不能用 Linux、Playwright 或交叉打包冒充通过：

- Apple Silicon Mac 上首次安装、右键打开未签名 App、DMG 拖拽安装流程。
- 通知权限允许和拒绝两种路径；Focus 模式下的通知行为。
- 登录时启动开关在系统设置里真实登记，重启登录后 Pomopet 自动启动。
- 透明宠物窗口在 Mission Control、多桌面、全屏 App、多显示器、不同缩放比例下不抢焦点、不丢失、不被错误遮挡。
- Mac 睡眠 5 分钟后唤醒，专注、休息、一次性提醒、间隔提醒的恢复语义正确。
- 系统时区变化或跨日后，今日番茄归属、每周提醒和下班提醒不乱。
- 连续后台运行至少 2 小时，CPU、内存、风扇、耗电没有明显异常。
